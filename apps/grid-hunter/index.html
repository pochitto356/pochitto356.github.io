GRID HUNTER

グリッドを支配せよ。

App Store で見る

画面いっぱいのグリッドフィールドを駆け回り、迫りくる敵を撃ちまくるエンドレスシューティング。左手で移動、右手で照準。5Waveごとに現れるボスを倒して、どこまで生き残れるか。

特徴

  • 左手で移動・右手で照準の両手操作。狙った方向へ弾は自動で出続ける
  • 5Waveごとに現れる3体のボス（ORBITRON / BLOCK CORE / CHAOS MATRIX）。それぞれ攻撃パターンが違う
  • コンボ50でGRID BREAK。全体爆破で盤面を一掃
  • 拾うと数秒だけ強くなる時限パワーアップ（反射弾・貫通レーザー・旋回する光刃）
  • 実績18種とスコアアタック
  • 横画面専用。iPhone / iPad対応

料金

基本無料。バナー広告あり。買い切り（¥300）で広告を削除できます。コンティニュー時にリワード広告を任意で視聴できます。
